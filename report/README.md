# User Guide

## How to Run the Project

1. Run DatabaseSetup.java
   - This will create the database and tables
   - It will also insert sample data

2. Run PetAdoptionApp.java
   - This will open the menu system

## Menu Options

1. View available pets  
   - Displays pets with status "Available"

2. View all adopters  
   - Displays all adopters stored in the database

3. Submit adoption application  
   - Enter adopter ID and pet ID  
   - Application will be saved and pet status updated

4. View adoption applications  
   - Displays all applications with adopter and pet details

5. View adopted pets  
   - Displays pets that have been adopted

6. Reset system  
   - Resets all pets to "Available"

7. View shelters  
   - Displays all shelters

8. Search pets by species  
   - Allows filtering pets by species (e.g., Dog, Cat)

9. Exit  
   - Closes the program

## Notes
- The database file is created automatically(petadoption.db)
- Running the setup multiple times will not cause errors
